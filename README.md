# App-Dom-Bosco
Aplicativo feito com intenção de auxiliar os jovens aprendizes da rede salesiana de Pernambuco, tirando dúvidas, informando sobre vagas e oportunidades, e certificações para implementação de currículo, links diretos para as páginas oficiais da rede salesiana e demais sites, e inteligência artificial carreeria, entre outros...
